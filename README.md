# ChatMargin

ChatMargin is a browser extension for people who use ChatGPT across long, complex or unfinished conversations.

It adds a lightweight local workspace next to ChatGPT so users can keep context without turning every conversation into a separate document.

## Product

- Notes attached to individual conversations
- Prompt drafts prepared before sending
- Follow-up tracking across conversations
- Local-first storage model
- Designed for consultants, researchers, founders, builders and writers who use ChatGPT as a serious work surface

## Current status

ChatMargin is publicly distributed through the Chrome Web Store and has its own product website.

Public website: https://chatmargin.app

Chrome Web Store: https://chromewebstore.google.com/detail/chat-margin-for-chatgpt/fnickbjgphdehoelanbchadempnlmmpc

## This repository

This repository contains the public website for ChatMargin, including the landing page, privacy page and product visuals. It is not the browser-extension source repository.

The site is intentionally lightweight and can be deployed as a static site.

## Why the project matters

ChatMargin is an example of end-to-end product execution around a concrete user problem: identifying friction in an existing workflow, defining a focused product, building the user experience, shipping publicly, handling privacy and product communication, and iterating after release.
